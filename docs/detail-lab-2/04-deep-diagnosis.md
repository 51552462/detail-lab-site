# 목표별 심층 진단 질문은행 v2

목적: 질문을 어떤 판단에 쓰는지 분명히 한다. 대상: 진단 담당자. 수정일: 2026-10-20. 버전: 2.0. 상태: 내부 시험 초안. 연결: 3단계 진단→공동 목표. 작성: ChatGPT, 검수: 디테일랩 운영자. 출처: 사용자 지시·기존 매뉴얼. 재검토: 업종별 실제 사례·자료 오류·불필요 질문 발견 때.

## 선택·완료 규칙

공통 질문: '이번에 바꾸려는 한 가지는?', '최근 잘된 건과 막힌 건은?', '현재 기준과 실제 처리가 다른가?', '무엇으로 변화를 볼 수 있나?', '그대로 지킬 것과 허용할 위험은?'. 기본 지표·권한·자료 사용 범위를 먼저 확인한다. 한 목표에 아래 모듈 1~2개를 선택하고 이유를 적는다. 10개 모듈을 최초 접수에 전부 묻지 않는다.

공통 필수: 최근 사건 1건의 설명, 현행 기준 또는 기준 없음, 측정 자료의 존재 여부. 선택 자료는 필요한 집계·발췌만 CSV/XLSX/PDF/이미지/텍스트로 승인 경로에 받는다. 직원·고객 실명은 역할/사건 코드로 치환한다. 자료가 없으면 기준선 수집을 먼저 설계하며 원인 판정을 유보한다. 사실표 F/T/H/U, 설명 불일치 절차, AI/사람의 역할은 접수 매뉴얼을 모든 모듈에 동일 적용한다.

## D01 매출·수익

- '결제 금액·제공한 서비스 금액·환불 중 어떤 수치가 줄었나요?' → 매출 인식·현금·환불 정의를 분리.
- '같은 영업일 기준으로 문의 수, 구매 수, 객단가 중 어디가 달라졌나요?' → 분해 지표 선택.
- '가격·영업시간·상품·직원·광고가 그 시기에 바뀌었나요?' → 대안 원인 기록.
- 증거: 같은 정의의 4~12주 집계, 영업일·할인·환불·직접 원가. 자료 부족 시 '총액에 무엇이 포함됐나요? 누락 결제와 중복은?'를 묻는다.
- 분석: 수납액 감소를 이익 감소로 단정하지 않음. 표본/계절/폐점일·상품 믹스 확인. 결과물: 매출 구성표·원가 확인 목록·작은 시험안. 지표: 순수납/영업일, 구매건/유효문의(같은 코호트·기간), 직접 공헌액. 분모 없으면 비율 산출 보류.

## D02 고객 응대·재방문

- '문의했지만 이용하지 않은 최근 한 건은 어디에서 끝났나요?' → 고객 흐름의 관측 가능한 이탈 위치.
- '답변과 실제 제공 조건이 달랐던 건은 있나요?' → 약속·제공 불일치.
- '다시 온 고객과 오지 않은 고객을 어떤 기준과 기간으로 구분하나요?' → 재방문 정의.
- 증거: 식별 제거 문의 3건·안내 버전·집계 코호트. 부족하면 '무응답/취소/이유를 들은 건을 구분할 수 있나요?' 추가.
- 분석: 이유 미응답을 가격 불만으로 분류 금지. 결과물: 안내 흐름·문장·재확인 카드. 지표: 같은 문의의 재질문, 응답 대기, 정의된 기간 재방문. 만족 자기보고와 거래 분리.

## D03 직원·조직·교육

- '각자가 맡았다고 생각한 일과 실제로 맡은 일이 달랐던 사례는?' → 역할 충돌.
- '새 직원은 기준을 어디에서 찾고 언제 누구에게 묻나요?' → 문서 접근·교육 흐름.
- '같은 일의 승인 범위를 대표와 담당자가 어떻게 설명하나요?' → 권한 불일치.
- 증거: 역할표·교육자료·익명 사건·당사자 설명. 부족하면 '규정이 없는가, 못 찾는가, 예외가 많은가?'를 분리.
- 분석: 인격·성향·능력 평가 대신 업무 조건을 본다. 노무 분쟁은 전문가 범위. 결과물: 역할/승인표·신입 한 업무 안내. 지표: 재설명·누락·실제 기준 조회 여부. 직원 동의 없는 AI 평가 없음.

## D04 대표 업무시간·운영 자율성

- '최근 쉬는 날 들어온 연락 중 즉시 대표만 결정해야 했던 것은?' → 위임 가능한 일과 위험 구분.
- '담당자가 결정하려면 어떤 정보나 권한이 없었나요?' → 병목 조건.
- '대표가 계속 맡고 싶은 일은 무엇인가요?' → 무조건 시간 감축 방지.
- 증거: 1주 역할별 시간 메모·부재 사건·현재 승인표. 부족하면 다음 한 주 간단 계수부터.
- 분석: 연락 감소와 미처리 증가를 같이 봄. 결과물: 대표 부재 처리표·보고 주기. 지표: 부재 중 비긴급 연락, 다음 날 미처리, 잘못 처리된 건. 안전·환불·인사·재무 권한은 임의 위임 금지.

## D05 업무 프로세스

- '일을 받은 때부터 끝났다고 아는 때까지 누가 무엇을 남기나요?' → 흐름과 완료 정의.
- '담당이 바뀔 때 무엇이 빠지나요?' → 인계 입력.
- '보통 때와 예외 때 절차가 어떻게 달라지나요?' → 표준화 가능한 범위.
- 증거: 업무 사건 2건·담당 역할·기록 시각·기준 버전. 부족하면 한 건을 동행 관찰하거나 현장 책임자 확인.
- 분석: 한 사람의 기억으로 전체 흐름 확정 금지. 결과물: 흐름 지도·인계 양식·예외 규칙. 지표: 접수→완료 시간(중앙값과 범위), 재작업, 완료 누락. 빨라져도 정확성 훼손이면 중단.

## D06 상품·서비스

- '고객이 산다고 이해한 내용과 실제 받는 것은 같은가요?' → 기대·제공 비교.
- '상품별로 시간·재료·공간을 얼마나 쓰나요?' → 용량·직접 원가.
- '가장 많이 팔리는 상품과 계속 제공하고 싶은 상품은 같은가요?' → 대표 목표와 거래 분리.
- 증거: 상품표·가격·제공 순서·익명 거래 집계. 부족하면 한 상품의 제공 시간부터 측정.
- 분석: 인기와 수익성 동일시 금지. 결과물: 상품별 포함/제외표·제공 용량 점검. 지표: 직접 공헌액/제공시간, 취소, 조건 재문의. 새로운 가격은 대표 승인 전 공개 금지.

## D07 브랜드·콘셉트

- '고객이 어떤 이유로 이곳을 골랐다고 직접 말했나요?' → 대표의 의도와 고객 진술 구분.
- '우리답다고 지킬 것과 실제 안내에서 다른 부분은?' → 유지 기준.
- '소개글·메뉴·상담에서 같은 상품을 어떻게 설명하나요?' → 접점 일관성.
- 증거: 공개 문구·상품표·권한 있는 익명 고객 진술. 부족하면 고객에게 실제 선택 이유 질문; 임의 페르소나 창작 금지.
- 분석: 예쁜 문구 선호를 구매 원인으로 보지 않음. 결과물: 강점 근거표·소개/안내 수정안. 지표: 조건 오해 재문의, 고객의 설명 이해, 실제 문의·구매는 따로 측정.

## D08 마케팅·홍보

- '어떤 고객이 어느 경로로 문의했는지 확인 가능한가요?' → 출처 추적 가능성.
- '광고 문구의 약속을 현장에서 모두 제공하나요?' → 과장·안내 불일치.
- '노출·문의·구매·환불을 같은 사람/기간으로 잇는 기록이 있나요?' → 퍼널의 분모.
- 증거: 승인된 채널 집계·광고비·게시 버전·익명 문의. 부족하면 출처 질문 한 칸부터.
- 분석: 조회수=매출 아님, 자기보고·로그·거래를 분리. 결과물: 채널별 약속표·하나의 문구 시험. 지표: 유효문의당 비용, 거래 확인된 유입, 환불. 표본 적으면 승자 단정 안 함. 계정 게시·광고비는 별도 승인.

## D09 데이터·업무 자동화

- '반복 작업의 입력과 최종 결과를 한 건씩 보여줄 수 있나요?' → 자동화 계약.
- '예외와 사람이 결정해야 할 지점은?' → 승인 경계.
- '공식 내보내기·API·관리 권한이 있나요? 실패하면 무엇으로 되돌리나요?' → 실제 연동 가능성.
- 증거: 가명 입력/출력 샘플·도구 목록·처리시간·오류 기록. 부족하면 수작업 한 번 재현.
- 분석: API 존재/키 보유/권한/운영 완료를 구분. 결과물: 입력 정의·실패 처리·수동 복구 매뉴얼. 지표: 건당 사람 시간, 오류·재처리, 승인 대기. 무권한 수집·개인정보 자동 AI 전송 금지.

## D10 외부 경제·시장

- '외부 변화가 어느 비용·고객·상품에 영향을 준다고 보나요?' → 노출 경로.
- '그 시기에 대출 조건·매입 단가·영업일·가격·광고도 바뀌었나요?' → 실제 노출·대안 원인.
- '이 정보를 보면 어떤 운영 결정을 바꿀 수 있나요?' → 쓸모 있는 지표만 선택.
- 증거: 공식 지표의 기준/발표/조회일·정의·단위, 고객의 해당 집계. 부족하면 거시 원인 판정 보류.
- 분석: 전국 지수와 한 지역 매장 매출의 인과 단정 금지. 결과물: 1쪽 환경 메모·다음 확인 질문. 지표: 노출 비용 비중·관련 원가·고객 변화, 수정한 운영 가설. 투자·자산운용 제외.

## 업종별 추가 확인

헬스/PT: 결제와 수업 제공 시차, 잔여 횟수, 담당 변경 약속·예약 정원·의료정보 제외. 식음/소매: 영업일·피크·재고·폐기·계절·규제 확인은 자격 범위 밖 표시. 예약형: 노쇼·취소 기준·정원·실제 제공 시간. 온라인: 주문/출고/반품 시점·플랫폼 수수료·공식 export. 프로젝트업: 단계별 검수·범위 변경·미수와 매출 구분. 1인업: 대표 부재·대체자 없음·수용량. 업종 경험 부족 시 전문성을 전제하지 않고 공통 질문만으로 충분한지 재판단한다.

완료 기준: 선택 이유·근거·미확인·대안 원인·유지할 점·가설별 반증·가능한 결과물·측정 정의·위험이 기록되고 대표가 다음 범위 합의에 참여할 수 있다. 자료량이나 질문 완료 수로 진단 품질을 대체하지 않는다.
