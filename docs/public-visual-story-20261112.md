# 홈페이지 공개: 역할 경험·전 업종 베타·운영 기록과 사업 방향

수정일: 2026-11-12. 대상: 디테일랩 운영자와 사이트 유지 담당. 버전: public-visual-story 1.0.
작성·기술 검수: ChatGPT. 공개 승인: 사용자의 ‘공개 시켜줘’ 요청. 실제 서비스 제공·고객별 판단: 디테일랩 운영자.
다음 검토: 최초 고객의 이해·접수·실제 사용 기록, 제공 범위 또는 데이터 처리 조건 변경.

## 공개 범위

- PR 29의 역할 경험 중심 소개와 업종 제한 없는 운영 점검 무료 베타를 공개한다.
- 헬스·PT 경험은 ‘경험의 출발점’에 남기며 타 업종의 실적·자격으로 표현하지 않는다.
- 기존 센터 베타 3곳·18문 사람 검토·결과 1장·가설 최대 3개·30일 행동 1개와 접수 경로는 보존한다.
- 새 베타는 최근 운영 문제 한 가지, 결과 1장·가설 최대 3개·실행 행동 1개·적용 시작일로부터 30일 후 확인 1회를 안내한다. 참여와 일정은 먼저 확인하며 무제한 모집으로 약속하지 않는다.

## 고객에게 보이는 연결

메인 진행 과정 → 운영 기록 미리보기 → B+C 사업 방향과 목표 이미지 → 무료 베타 상세 안내.
상단 ‘변화와 기록’과 서비스 페이지 데이터 설명에서 연결한다.

운영 기록 미리보기의 세 선택지는 대표에게 몰리는 결정, 반복 고객 문의, 업무 분담과 인수인계다. 각각 현재 장면·만들 자료·적용 후 볼 기록·역할·다음 판단을 보여준다. 실제 성과가 없는 상태에서 숫자나 상승 그래프를 채우지 않는다.

사업 구조 그림은 목표 → 업무 기준 → 실제 사용 → 기록과 재점검의 순환을 설명한다. 별도 목표 이미지는 대표의 시간·고객의 이해·업무의 연속성을 설명한다. 작은 화면에서는 세로 그림으로 전환한다. SVG는 수정 가능한 원본이며 대체 설명을 함께 제공한다.

## 기능의 정확한 상태

| 항목 | 이번 구현 |
| --- | --- |
| 운영 기록 미리보기 | 실제 동작하는 설명용 탭 화면, 가상 상황 표시 |
| B+C 구조와 목표 이미지 | 반응형 SVG, 서비스·베타 안내와 연결 |
| 고객 로그인·실데이터 대시보드 | 구현·출시 범위 아님 |
| 자동 수집·자동 분석·자동 템플릿 갱신 | 구현·출시 범위 아님 |
| 유료 상품·결제 | 공개 확정 요금제로 변경하지 않음 |
| 개인정보 접수 | 기존 이메일과 센터 경로 유지, 새 서버·파일 수집 없음 |

미리보기 JS는 선택 화면만 바꾼다. 네트워크 요청·자료 저장·AI 호출이 없다. 내부 수익·시간 계산기나 고객 원본을 공개 영역에 추가하지 않는다.

## 검수와 배포 기준

로컬 정적 검사: 14개 HTML의 링크·앵커·ID·인라인 JavaScript 검사 통과. 새 JS와 CI 스크립트 문법 검사 통과. SVG 3개 XML 파싱 통과.
로컬 브라우저: PC의 세 선택지와 키보드 Home·오른쪽 이동, 활성 패널 1개, 두 방향 이미지 로딩을 확인했다. 390px 프레임에서 선택 동작·세로 이미지 전환·베타 이동·가로 넘침 없음을 확인했다. 실제 휴대폰 검수와 실고객 사용은 포함하지 않는다.

GitHub Actions에서 기존 도구·새 화면·내부 합성 자료 경계에 대한 기존 검사를 통과한 커밋만 병합한다. Render의 기존 main 자동 배포를 사용하며 live 상태와 실제 공개 파일·브라우저 동작을 별도로 확인한다. 이 문서의 코드 작성만으로 공개 반영이나 실고객 검증을 완료했다고 판단하지 않는다. 배포 커밋·상태·최종 검수는 PR과 내부 노션에 남긴다.

## 운영자가 다음에 확인할 것
