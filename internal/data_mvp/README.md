# 합성 자료 전용 로컬 자료 처리기

상태: 개발·시험용. 실고객 데이터, 공개 업로드, 로그인, 암호화·백업 운영, 고객 전달, AI·통계 API·자동 재시도는 미구현입니다. 실제 고객 ID는 코드에서 거부합니다. 운영 시스템으로 배포하지 마세요.

Python 3.12, openpyxl 3.1.5에서 확인합니다. 테스트는 임시 디렉터리의 합성 CSV/XLSX를 만들고 종료 후 정리합니다.

```sh
cd internal/data_mvp
python3 -m unittest -v
```

Store(root, 'SYN-A') → add_metric → ingest → review → report 순서입니다. review는 개발용 역할 문자열이며 실제 사용자 인증이 아닙니다. 모든 import에 출처·기간을 요구합니다. 등록하지 않은 지표 정의·추가 열·중복·날짜/숫자 오류를 거부합니다. 같은 파일/메타데이터는 재적재하지 않고 내용이나 출처/기간 변경은 새 승인 버전으로 둡니다. 최신 버전이 미승인이면 보고를 차단합니다. 보고에는 원자료 버전·정의·단위만 담으며 임의 합산·인과·연간 예측은 하지 않습니다.

실제 고객용 전환 전: 계약/자료 권한·보관·동의·AI 처리 검토, 서버 인증과 고객 경계, 파일 보안·접근 로그·삭제/백업·복구, 역할별 승인과 예산·운영자 책임을 별도로 구현·검증해야 합니다. 로컬 tenant 검사는 이 검증을 대신하지 않습니다.
