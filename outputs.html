01 현재 상황을 어떻게 봤나요?

유지할 강점

고객에게 한 약속을 교대 기록에 남긴다는 대표의 설명이 있습니다. 이 기록이 실제로 인계에 사용되는지 확인하고, 유용한 방식은 새 기준에도 남깁니다.

먼저 보완할 부분

예약 변경을 담당자가 어디까지 결정할 수 있는지 서로 다르게 이해할 가능성이 있습니다. 모든 연락을 불필요한 연락으로 분류하지 않고, 대표 승인이 필요한 예외와 일상 처리를 나눕니다.

추가로 확인할 부분

담당자의 설명과 실제 요청 기록이 아직 없습니다. 업무가 몰린 시간대나 예약 도구 문제로 처리가 늦어진 가능성도 확인해야 합니다. 직원의 태도나 역량으로 원인을 단정하지 않습니다.

02 이번에 만들 자료는 무엇인가요?

예약 변경 한 업무의 처리·승인표입니다. 요청 유형, 담당자의 처리 범위, 대표 확인이 필요한 예외, 고객에게 안내할 내용, 교대 시 남길 기록을 정리합니다. 실제 사용자와 대표가 같은 뜻으로 이해하는지 확인한 뒤 적용합니다.

자료의 항목현장에서 답할 질문
처리할 수 있는 범위어떤 요청을 담당자가 직접 처리하나요?
대표 확인이 필요한 예외어떤 상황에서 결정을 넘기나요?
고객 안내지금 확정할 것과 확인 후 답할 것은 무엇인가요?
완료와 인계누가 처리 결과와 남은 일을 어디에 남기나요?

03 누가 무엇을 하나요?

담당맡는 일완료 확인
디테일랩현재 설명 정리, 처리표 제작·설명, 합의한 수정과 사용 점검합의한 항목·버전 전달과 설명
대표처리 권한·예외·고객 약속 결정, 현장 적용 승인기준과 적용 기간 확인
현장 담당자합의한 기준 사용, 막힌 상황과 인계 기록사용 여부와 실제 반응

04 적용 후 무엇을 확인하나요?

요청이 생긴 건수, 대표 확인이 필요했던 건수, 미처리와 잘못된 안내, 실제 처리표 사용을 같은 기간·정의로 남깁니다. 기준선이 없으면 변화율을 만들지 않습니다. 연락이 줄었더라도 고객 혼선이나 업무 누락이 늘면 기준을 수정합니다.

다음 점검의 결정

기준이 실제로 쓰이고 혼선이 없으면 유지합니다. 찾기 어렵거나 설명이 다르면 문장과 위치를 고칩니다. 고객 불편·권한 충돌이 생기면 해당 적용을 멈추고 대표가 복구 범위를 결정합니다.

실제 보고서는 고객의 자료와 합의한 범위에 맞춰 작성합니다. 이 예시의 결론을 다른 업장에 그대로 적용하지 않습니다.
