## 2. HOW · 어떻게 확인하고 고치는가

| 영역 | 고객 입력 → 받는 것 → 직접 확인할 것 |
| --- | --- |
| 센터 운영 | 12개 선택 답 → 이번 주 카드. 별도 신청·선정 후 18문 → 사람이 읽은 결과 1장과 30일 행동. 결과와 실제 현장 장면을 대조해야 한다. |
| 작은 가게 | 12개 선택 답 → 7일 카드와 선정 근거. 결과에서 실제 요청 한 건, 다음 담당자·시점, 7일 뒤 확인할 것을 직접 적어 복사한다. 교대만 따로 12문으로 확인할 수도 있다. |
| 직장 선택 | 면접 전 질문 또는 A·B에서 들은 말과 문서 확인 표시 → 빈칸·들은 말·확인 표시를 나눈 기록. 자료 자체의 진위와 계약 적법성은 판정하지 않는다. |
| 수업 조건 | 두 사람이 같은 기기에서 각자 7문·공유 동의 → 조건 대조와 첫 대화 질문. 실제 예약 가능 시간·장소·비용은 직접 확인한다. |

## 3. WHO · 누가 무엇을 책임지는가

- 디테일랩은 PT샵 운영 경험을 출발점으로 소개하지만, 운영자의 신원·자격·실고객 성과를 이 저장소만으로 검증할 자료는 없다. 이를 보충하려고 인물 사진이나 후기를 만들어 넣지 않는다.
- 브라우저 도구의 답은 사용자가 고르고 자기 기기에서 복사한다. 디테일랩은 이 답을 읽지 않는다. 센터의 별도 18문 진단에 선정된 곳의 답만 사람이 검토한다.
- 가게 카드는 운영자가 예외 범위를 정하고 직원과 실제 문장을 확인한다. 직장 기록은 지원자가 채용 담당자에게 되묻는다. 수업 대조는 두 사람이 동의한 뒤 직접 조건을 조율한다. 각 영역의 책임자를 하나로 합치지 않는다.
